---
name: application-assistant
description: Review queued jobs, prepare truthful application drafts, and track user-authorized submissions.
---
Read the private queue and user-approved profile. Verify the current official posting and requirements using available host tools; ask rather than infer personal answers. In review mode inspect only; in draft mode `python3 workflow.py draft ID` creates a private outline after the job reaches preparing or waiting_user. For a candidate-approved private JSON profile, `python3 application.py ID --profile private/candidate.json` creates a Markdown resume-content section and cover-letter draft; facts are copied, not independently verified. The user must review all factual claims, resume and answers. Submit mode is intent, not CLI automation: use a permitted host browser only, obtain explicit user authorization for each final submission, and stop at security challenges. Before the final click mark `submission_unknown`; after interruption or uncertainty, inspect official confirmation before retrying. Mark `submitted` only with reliable confirmation and a minimal evidence reference. If the official source confirms no submission, use `resolve-not-submitted` with a minimal evidence reference before retrying. A bookmark is not an application. Never record passwords, codes, cookies or full sensitive form answers in the queue.
