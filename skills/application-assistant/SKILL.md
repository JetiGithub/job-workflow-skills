---
name: application-assistant
description: Review queued jobs and prepare applications with user involvement.
---
Read the local queue and user-approved profile. Verify current posting and requirements through available host tools; ask rather than infer personal answers. Review mode only reviews; Draft mode may prepare materials locally with user approval of factual claims. Submit is a requested workflow, not an implemented automation: use only a host with permission, obtain user authorization for each final submission, and do not bypass security. Before any final submit, record `submission_unknown`; after interruption or uncertain response, investigate the official portal or confirmation before retrying. Mark `submitted` only after reliable confirmation and record a minimal evidence reference. A bookmark is not submission. Never record passwords, codes, cookies, or full sensitive form answers in the queue.
